## C. Decisiones

- Confirmadas. El conductor define el viaje, la USC admite distintos roles y el pasajero elige un tramo autorizado. La ruta publicada permanece inmutable. Afiliación, permiso del propietario, documentos, reloj, capacidad y compatibilidad de citas se validan en Nest.
- Técnicas. Conservar la tabla y contrato de catálogo anteriores, ampliar `TripStop` y guardar LineString GeoJSON en JSONB. PostgreSQL serializa las reservas por conductor y viaje. Sin nueva dependencia de paquete ni PostGIS. OSRM y teselas raster se habilitan por configuración. Una publicación con puntos ordenados comunica la ausencia de geometría si no hay motor o archivo.
- Provisionales. Contacto USC exigido en al menos un punto de encuentro, con una referencia declarada cuando el punto interno es personalizado. El radio de matching lo elige el pasajero dentro del intervalo RF-005. La geometría admite 150 m de ajuste entre punto y vía, y la búsqueda usa la hora de salida. Cupos por viaje completo y solicitud con el responsable incluido. Se conserva el modelo de aprobación del dueño.
- PO. Alcance sin vínculo USC, edición tras confirmación, cancelaciones de confirmadas, consentimiento del grupo y reglas de reutilización por tramo. El código DEMO de grupo es el UUID estable que el miembro comparte. El consentimiento documentado/rotación de códigos es pendiente para uso real. Mantener sin cargos. Véase [decisiones abiertas](../decisions/OPEN_DECISIONS.md).

## E. Validación

- `npm run typecheck`, `npm run lint` y `npm run format:check` aprobaron. `npm test` aprobó 81/81 en ocho suites. La carrera por la última plaza devuelve un 200 y un 409 y conserva una plaza ocupada. Las dos solicitudes recíprocas de conductores reciben 201 mediante el lock `FOR NO KEY UPDATE` sobre el conductor.

- `npm run check:env`, `npm run db:generate`, `npm run db:test:setup`, `npm run db:migrate` y `npm run db:seed` ejecutados. Las seis migraciones aplicadas; una base separada con un viaje creado bajo las cuatro migraciones anteriores conservó ID, destino, coordenadas y parada al migrar. `prisma migrate diff --from-config-datasource --to-schema prisma/schema.prisma --exit-code` devolvió «No difference detected».
- `npm run smoke`, 6/6 con PostgreSQL y la API real. `npm run build:api`, `npm run build:web`, export Android, `expo install --check` y Expo Doctor (18/18) ejecutados. La exportación Android se escribió fuera del repositorio.
- Una ejecución intermedia de Jest agotó el tiempo de hooks de arranque mientras Metro compilaba. Las suites se repitieron sin concurrencia con la compilación. Los mensajes de deprecación de `pg` se observaron también en las suites de regresión. El escenario de motor sin configurar produce HTTP 503 previsto. El primer format:check registró 67 avisos de guías vendorizadas del baseline. Se excluyó sólo backend/.agents/skills del formateo.
- Pruebas basadas en casos A–E. Hay fixtures sintéticos de Plazoleta de los Sabios, sótano 1/2, Calle Quinta y Floralia. Las pruebas HTTP verifican destinos externos vinculados, dirección, horario, proximidad, parada de paso, duplicados, grupo/afiliación, concurrencia y cancelaciones. El último `npm run test:e2e` aprobó 4/4 en Chromium, en escritorio y viewport iPhone 13, con cuentas separadas. Se inspeccionaron las capturas del recorrido y de selección de puntos. Browser plugin no disponible; se usó la configuración Playwright del repositorio.
