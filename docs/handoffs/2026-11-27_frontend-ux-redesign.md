# Handoff de frontend, navegación y mapas

27 de noviembre de 2026 · `task/frontend-ux-redesign` desde `2b69336` de feature

La ejecución local añade identidad azul, temas, barra inferior y lateral, inicio por
contexto real, un mapa Expo compartido y organización visual de viaje, publicación,
operación, cuenta, actividad y mensajes. La configuración de teselas mantiene su
URL y atribución y distingue indisponibilidad. No se encontraron archivos de video
de referencia en el checkout o los adjuntos disponibles; se usaron fuentes
oficiales y un concepto propio. Las capturas proceden de la app ejecutada.

Las pruebas Playwright usan la API real, usuarios de prueba que atraviesan el login
convencional y PostgreSQL temporal con el esquema existente. Las respuestas
cartográficas controladas se usan para verificar gestos, coordenadas y selección
vial. Las suites, las capturas y las condiciones comprobadas se registran en la
[validación visual y técnica](../reviews/FRONTEND_UX_VALIDATION.md).

Revisión por Frontend, Cartografía, Identidad e Integración. Mantener la coordinación
con los cambios del otro computador para edición, descenso individual, lugares
habituales, guardados, seguimiento continuo, offline y push. Las decisiones de
privacidad y requisitos de proveedor, así como Expo Go físico, requieren su ambiente
real. No promover este trabajo hasta la revisión del equipo.
